🕌 Azkary (زاد المسلم)
An Android Islamic app built with Capacitor and Java, featuring accurate prayer times with full-screen Adhan alarms, a home screen widget, a floating bubble, and a wake-up quiz to dismiss Fajr alarms. Includes custom Muezzin audio, Hijri dates, AdMob integration, and background scheduling.

📥 Download
Get it on Google Play

🔗 Direct Link: https://play.google.com/store/apps/details?id=com.azkary.azkar2026

✨ Features
🕌 Prayer Times & Adhan: Accurate offline/online calculation with full-screen alarm.

🔔 Wake-Up Quiz: Solve 3 math questions to dismiss the Fajr Adhan.

🎵 Custom Muezzin: Select or import your own Adhan audio files.

📱 Home Screen Widget: Shows prayer times, Hijri date, and a daily Ayah.

💬 Floating Bubble: Quick access to Azkar over other apps.

🌙 Hijri Date: Umm al-Qura calendar support.

📊 AdMob: Banner, Interstitial, and App Open ads integrated.

🛠️ Tech Stack
Frontend: Capacitor (HTML/JS)

Backend: Java (Android Native)

Ads: Google AdMob

APIs: Aladhan API (Prayer Times)
